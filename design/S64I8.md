# S64I8 prototype (superseded)

The balanced-digit, 68-bit prototype has been replaced by
[S64U8](S64U8.md), the fixed-width working format.

The project contract is at least binary64 range and resolution using small-width
integer arithmetic. The prototype's 68-bit precision was an implementation
choice, not a permanent rounding target or a requirement for per-operation
binary64 equivalence. The active design retains 256-bit working precision in
32 unsigned bytes, uses bounded scratch storage, and converts explicitly to
f64 or f32. Arithmetic `_f64` variants and the S64I8 API have been removed.
